from per-type seconds. Tom's device holds the truth: real per-type medians accrue in telemetry

## The finding

- **The "too short" lessons are the MACHINE lessons: 8 beats, ~5.3 paper-minutes each**
  (drill with 4 cues + weld x2 + exchange x2 + close). At Tom's measured pace this is
  plausibly 2-3 real minutes. All seven machines are identical in size regardless of frame.
- Ladder lessons run 29-55 beats (11-18.5 paper-minutes) - if these ALSO feel short, the
  per-exercise time estimates are the problem (Tom's hypothesis), and the telemetry line
  settles it.

## The unused depth levers (Tom's instinct, quantified)

- **Exchange replies: 28 authored, 2 served per lesson.** The single biggest sitting asset.
- Conveyor: one serve per filler (the flow ruling left drill depth to practice sessions).
- Welds: 2 of 4 possible per machine lesson.
- The composer guard's 49 legal welds: only the close touches them (1 per lesson).
- Variations of sentences (Tom's ask): the variants field + the weld system can generate
  much more "same frame, slight change" material than any lesson currently serves.

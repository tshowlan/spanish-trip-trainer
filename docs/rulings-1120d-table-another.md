## 4. NOTE 10, "WHEN THE SERVER FORGETS": something is missing from the table

Tom (11/20): it is when the server brought one glass and not two, or the knife never came. That is neither "one more of the same" nor an order that never arrived: the table is short a thing. The word is **falta**, and it gets a card and two lines, which also gives cuchillo the sentence it lacked.

```js

          { frame: "falta", es: "Perdón, falta un cuchillo.", en: "Excuse me, a knife is missing.", hint: [["Excuse me,", "perdón"], ["a knife", "un cuchillo"], ["is missing.", "falta"]], near: ["Excuse me, a fork is missing.", "Excuse me, the knife is for me."], replies: [["¿Solo el cuchillo?", "Just the knife?"], ["Vale", "Okay"], ["Ahora mismo", "Right away"]] },
```

- The frame tag is composer-only; the card leads its two lines, as the pago card does.
- "Could you bring me another glass?" is deliberately NOT a near miss here: when one is missing it means nearly the same thing, and a near miss must be clearly wrong.
- Unsourced word for word, like the rest of the batch's lines; falta in this sense is dictionary-level.

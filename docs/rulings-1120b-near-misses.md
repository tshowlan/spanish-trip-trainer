# Tripfluent: two near misses swapped, no prep line (chat, 2026-11-20, later)

*Chat's reply to Tom's ask on the fryer sentence's wrong answer "Is the kitchen shared?" (docs/chat-ledger.md, 11/20). Pasted by Tom into Code; recorded here. Rides `trip-celiac`.*

## The ruling

1. **Swap it.** On ¿La freidora es compartida?, "Is the kitchen shared?" becomes **"Is the grill shared?"**. A distractor should be something a diner might plausibly ask, or it is noise. The grill is a real shared surface and it is still one word off.
2. **The same flaw in a second place (chat's own).** On ¿Hay contaminación cruzada?, "Is there a separate kitchen?" becomes **"Is there a separate fryer?"**.
3. **No new prep line.** ¿Hay contaminación cruzada? already does that job, and the good answer heard back, "No, lo hacemos aparte," is the prep answer. Celiac already has eight Table lines.

**Rule for near misses from here:** a wrong answer must still be something a diner could plausibly ask.

## If a prep line is ever wanted

The sourced form is **¿Me lo pueden hacer aparte?** (Can you make it separately for me?), not Code's "preparar" draft: the Madrid celiac association's verb is hacer. It is a request where the cross-contamination line is a question.

**Tom's answer (11/20):** he does not ask for a dish to be made separately. He mentions the allergy, asks about shared fryers, and sometimes cross-contamination comes up in conversation. So the set matches what he does and no prep line is added.

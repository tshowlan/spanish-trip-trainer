## 1. New card: Para compartir

| | |
|---|---|
| Card | **Para compartir** / To share |
| Word by word | Para = to · compartir = share |
| Example | Para compartir, pan con tomate. (To share, bread with tomato.) |
| Good to know | The same Para as Para mí, now for the whole table. It is also a heading on menus: the plates under Para compartir are the ones made for sharing. |

The "Para mí, ___" card is unchanged and stays beside it.

## 3. New card and two converted sentences: Queremos

| | |
|---|---|
| Card | **Queremos** / We want |
| Example | Queremos agua para la mesa. (We want water for the table.) |
| Good to know | Quiero is I want. Queremos is we want: the same ask, said for the table. |

|---|---|

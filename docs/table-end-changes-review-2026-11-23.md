## 3. Four things worth knowing before you play

1. **The Counter is longer for a dietary learner.** Counting the dietary lines apart adds about five questions per answer: 31 questions with no dietary answers, 36 with one, 43 with three.
2. **A lactose-intolerant learner now gets a "Your table lines" row with two lines.** That plays as a four-question session. Chat ruled it without an exception; say if it feels too thin to be a row.
3. **Table words · Part 2 passes nine words for a learner with several dietary answers.** Chat counted nine at most; my fullest test set-up has eleven (it had ten before postre).
4. **One group still passes three:** a learner with four or more allergies has one "¿Lleva ___?" line per allergy. With chat.

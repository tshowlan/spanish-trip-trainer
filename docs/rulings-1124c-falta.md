## 2. THE RULE IS ABOUT SENTENCE STRUCTURE, NOT VOCABULARY (Tom)

The register in the framework is re-scoped and renamed NEW SENTENCE STRUCTURES.

- **A structure** is a way of building a sentence the learner has not used: a tense, a command, a new shape.
- **A new verb or adjective inside a shape the learner owns is vocabulary.** The card rules govern it; the register does not.
- **Seven rows remain:** the past (Ya he terminado) · Falta ___ · the command (Llame a ___) · the short request (¿Me pone?, ¿Me cobra?) · the we-form (Queremos) · and two heard rows (quiere / quieren; the staff's le / lo + verb).
- **Ten leave the register as vocabulary:** pedir, comer, pago, es, lleva, tengo, soy, como, no entiendo, Está bien así.
- **For Code going forward:** add a row only when a line brings a tense, a command, or a sentence shape no earlier line has.

Nothing is built on any row unless a later chapter's own content calls for it.
